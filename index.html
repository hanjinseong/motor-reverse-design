Design

Problem-card agent

AGENT 02
Generation

Explore · exploit · filter

Breeds a generation from Pareto parents: zero-shot topology moves and fine-tuned text edits, then a feasibility gate and embedding-based filtering.

Evaluation

CAD → FEA → ε-dominance
