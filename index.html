AGENT 01
Design

Problem-card agent

Chats with you and turns a reference image, the rotor/stator envelope and the objectives into a Design Problem Card.

image + envelope + objectives → problem card
Open
AGENT 02
Generation

Explore · exploit · filter

Breeds a generation from Pareto parents: zero-shot topology moves and fine-tuned text edits, then a feasibility gate and embedding-based filtering.

parents → 200 images → gate → N11 + FPS → 60
Open
AGENT 03
Evaluation

CAD → FEA → ε-dominance

Converts images to STEP, solves Maxwell 2D, judges ε-dominance vs the parent, writes improvement directions and updates the operator scoreboard.

RGB → STEP → FEA → ε vs parent → scoreboard
